# 🚌 버스 알리미 (Bus Alert App)

`bus_notifier.py`(GitHub Actions + 텔레그램 1회성 알림)를 **모바일 앱**으로 옮긴 프로젝트입니다.
조회 로직(대전·세종·대구·인천·광주·울산 TAGO / 성남·경기 GBIS / 서울)과 알림 판단 규칙은 그대로이고,
앱에서 **정류장·노선·시간대·요일·반복 간격·하차 알림**을 직접 설정하고 휴대폰 알림으로 받습니다.

React Native + Expo (SDK 58, Expo Router, TypeScript)로 만들었고 Android와 iOS를 모두 지원합니다.

## 주요 기능

| 기능 | 설명 | 원본 대응 |
| --- | --- | --- |
| 정류장·노선 알림 여러 개 | 권역, 5자리 정류소 번호, 노선(여러 개 가능, 비우면 전체) | `TARGETS_JSON` |
| **정류장 검색·지도 선택** | 이름 검색(예: 명석고) 또는 지도에서 주변 정류장 선택. 같은 이름 정류장은 "→ ○○ 방면"과 지도 화살표로 방향을 구분. 현재 위치로 권역 자동 설정 | 신규 |
| 정류소 번호 직접 입력 | 고급 옵션. 번호로 이름/내부 ID 조회 | `resolve_*_id` |
| 알림 시간대 | 시작~종료 시각, 자정 넘김 지원 (예: 23:00~01:00) | `WINDOW_START/END` |
| 반복 요일 | 요일 선택 + 평일/주말/매일 프리셋 | cron 스케줄 |
| 도착 N분 전 | 1~30분 | `ALERT_THRESHOLD_MIN` |
| 조회 간격 | 30~300초 | `POLL_INTERVAL_SEC` |
| 반복 알림 | 같은 버스를 도착 전까지 N분마다 다시 알림 (0 = 버스당 1회) | 신규 |
| 감시 시작 요약 | 시간대가 시작되면 가장 가까운 버스 현황 1회 알림 | `SEND_START_SUMMARY` |
| 지금 조회 / 테스트 알림 | 시간대와 관계없이 즉시 1회 조회·알림 | `RUN_ONCE_NOW` |
| **하차 알림** | 내릴 정류장을 지정하면 GPS로 미리 알림(예: 800m) + 도착 알림(예: 200m) N회 반복 | 신규 |
| 텔레그램 동시 전송 (선택) | 기존처럼 텔레그램 봇으로도 전달 | `send_telegram_message` |

새 버스 판단 규칙은 원본과 같습니다. 차량번호가 있으면 번호로 비교하고, 없으면 남은 시간이 120초 이상 늘었을 때 다음 버스로 봅니다.

## 화면

- **홈**: 백그라운드 감시 상태, 하차 알림 카드, 알림 목록(켜기/끄기, 감시 중이면 실시간 도착 정보, 아니면 다음 감시 시각)
- **버스 알림 설정**: 정류장·노선 / 알림 시간·요일 / 알림 방식 / 지금 조회·테스트 알림 / 삭제
- **하차 알림**: 내릴 정류장 조회(좌표 자동 입력) 또는 "현재 위치로 지정", 반경·미리 알림 거리·반복 횟수/간격, 진행 중이면 남은 거리 표시
- **설정**: 공공데이터 API 키(기기에 암호화 저장), 텔레그램, 권한 확인, 테스트 알림, 활동 기록

## 시작하기

### 1. 준비물

- Node.js 20 이상
- [공공데이터포털](https://www.data.go.kr) 인증키. 사용할 권역에 맞춰 아래 API를 활용신청해 두세요.
  - 국토교통부_(TAGO)_버스도착정보, 국토교통부_(TAGO)_버스정류소정보, 국토교통부_(TAGO)_버스노선정보 (대전 등 TAGO 도시, 성남 폴백 / 노선정보는 방면 표시용)
  - 경기도_버스도착정보 조회(v2), 경기도_정류소 조회(v2) (성남/경기)
  - 서울특별시_정류소정보조회 (서울)

### 2. 설치·실행

```bash
cd bus-alert-app
npm install
npx expo run:android   # 또는 npx expo run:ios (macOS + Xcode)
```

> 백그라운드 위치·작업 매니저 같은 네이티브 모듈을 쓰기 때문에 **Expo Go에서는 백그라운드 알림이 동작하지 않습니다.**
> 위처럼 개발 빌드를 쓰거나, 아래 "폰에서 바로 테스트하기"의 APK를 설치하세요.

### 3. 앱 첫 설정

1. **설정**에서 공공데이터 API 키를 입력하고 저장합니다.
2. **권한 확인 / 요청**에서 알림 권한과 위치 권한을 **"항상 허용"** 으로 허용합니다.
   Android는 배터리 최적화를 "제한 없음"으로 바꾸는 것을 권장합니다.
3. 홈에서 **＋ 추가**를 누르고 정류장 번호 입력 → **정류장 확인** → 노선 선택 → 시간·요일·알림 방식을 정한 뒤 저장합니다.
4. **테스트 알림**으로 연동을 확인합니다.

## 📲 폰에서 바로 테스트하기 (푸시 → APK 자동 빌드)

`bus-alert-app/`을 수정해서 아무 브랜치에나 푸시하면 GitHub Actions(`.github/workflows/app_android_apk.yml`)가 Release APK를 빌드합니다. Expo 계정은 필요 없습니다.
빌드된 APK는 항상 같은 링크에 덮어써집니다.

**설치 링크:** https://github.com/etaeho/bus_noti_alert/releases/download/app-dev/bus-alert.apk

- 폰 브라우저로 링크를 열어 설치합니다. 처음 한 번은 "출처를 알 수 없는 앱" 설치를 허용해야 합니다.
- 서명 키가 항상 같아서 새 APK를 받으면 기존 앱 위에 그대로 업데이트됩니다. 설정과 알림 목록도 유지됩니다.
- 빌드는 푸시 후 약 10~20분 걸립니다. 진행 상황은 저장소의 Actions 탭에서 볼 수 있습니다.
- 설치된 버전은 앱의 **설정 → 앱 버전**에서 확인합니다(빌드 번호·커밋). 같은 화면의 **최신 APK 받기** 버튼으로 바로 내려받을 수 있습니다.
- 최신 64비트(arm64) 폰 전용으로 빌드합니다.

## 백그라운드 동작 방식

모바일 OS는 앱이 백그라운드에서 1분마다 네트워크를 쓰는 것을 기본적으로 막습니다. 그래서 다음처럼 겹겹이 구성했습니다 (`src/services/background.ts`).

1. **위치 업데이트 태스크 (주 엔진)**
   켜진 알림이 있으면 위치 업데이트를 받습니다. 업데이트가 올 때마다 감시 틱을 실행하고, 각 알림의 조회 간격과 시간대를 지켜 API를 호출합니다.
   - Android: 상시 알림("🚌 버스 알림 감시 중")이 붙은 포그라운드 서비스로 실행되어 앱을 닫아도 약 30초마다 깨어납니다.
   - iOS: 백그라운드 위치 모드로 실행됩니다. 상태바에 위치 사용 표시가 나타납니다.
2. **지오펜스**: 하차 알림을 켜면 내릴 정류장 반경(최소 100m)을 OS에 등록합니다. 앱이 멈춰 있어도 OS가 진입을 감지해 깨웁니다.
3. **BackgroundTask (15분 이상 간격)**: 위 둘이 중단됐을 때 보조로 실행됩니다.
4. **감시 시작 안내 예약 알림**: 각 감시 시작 시각에 OS 예약 알림을 띄웁니다. 백그라운드 실행이 완전히 끊겨도 이 알림을 누르면 앱이 열리면서 감시가 다시 시작됩니다. 설정에서 끌 수 있습니다.

앱이 화면에 열려 있으면 10초마다 감시 틱이 돕니다.
여러 경로에서 동시에 실행돼도 저장소 락이 걸려 있어 알림이 중복으로 가지 않습니다.

### 알려진 제약

- **iOS**: 기기가 오래 정지해 있으면 위치 업데이트가 뜸해질 수 있습니다. 사용자가 앱 전환기에서 앱을 위로 밀어 강제 종료하면 iOS가 백그라운드 위치 업데이트를 멈춥니다. 이때 지오펜스와 4번 안내 알림이 보완합니다.
- **Android 제조사 절전 정책**(삼성, 샤오미 등): 배터리 최적화 예외로 설정해야 안정적으로 동작합니다.
- **하차 알림**은 GPS 거리 기준입니다. 정류장 좌표를 API에서 받지 못하면 정류장에서 "현재 위치로 지정"을 쓰거나 좌표를 직접 입력하세요.
- 시간대·요일 판정은 기기 시간대를 따릅니다(국내 사용 기준 KST).

## 프로젝트 구조

```
bus-alert-app/
├── index.ts                    # 진입점: 백그라운드 태스크 정의 → expo-router
├── app.json                    # 권한, 백그라운드 모드, 평문 HTTP 허용(ws.bus.go.kr) 등
├── src/
│   ├── app/                    # 화면 (Expo Router)
│   │   ├── _layout.tsx
│   │   ├── index.tsx           # 홈
│   │   ├── alarm/[id].tsx      # 알림 추가/수정
│   │   ├── ride.tsx            # 하차 알림
│   │   └── settings.tsx        # 설정
│   ├── core/                   # 순수 로직 (OS 의존성 없음, 단위 테스트 대상)
│   │   ├── busApi.ts           # TAGO / GBIS / 서울 API (bus_notifier.py 이식)
│   │   ├── decide.ts           # 알림 판단 (새 버스·반복·요약·하차 거리)
│   │   ├── schedule.ts         # 시간대·요일 계산
│   │   ├── format.ts           # 알림 메시지 포맷
│   │   └── types.ts
│   ├── services/
│   │   ├── background.ts       # 위치/지오펜스/백그라운드 태스크, 서비스 모드 관리
│   │   ├── monitor.ts          # 감시 틱 엔진
│   │   ├── notify.ts           # 로컬 알림, 채널, 텔레그램, 예약 안내
│   │   ├── runtime.ts          # 앱 실행 중 타이머 및 상태 훅
│   │   └── storage.ts          # AsyncStorage + SecureStore
│   └── components/ui.tsx       # 공통 UI (라이트/다크 테마)
└── tests/core.test.ts          # 핵심 로직 테스트
```

## 개발 명령

```bash
npm run typecheck   # TypeScript 검사
npm test            # 핵심 로직 단위 테스트 (node:test)
npx expo start      # 개발 서버 (개발 빌드와 함께 사용)
```
